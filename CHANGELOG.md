# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-27
### Added
- Initial enterprise release of Azure Private Networking Landing Zone.
- Centralized Private DNS Zones for Storage Blob, Key Vault, and Azure SQL.
- Automated Private DNS Zone Virtual Network link associations.
- Reusable Private Endpoint module with automated Private DNS Zone Group registration.
- Pre-configured dev and prod deployment environments.
- Comprehensive documentation and Mermaid architecture diagrams.
